## How These Were Generated

Each sample was generated by calling the MCP tools directly:

```
build_commander_deck("Najeela, the Blade-Blossom", budget=300)
price_cube("e3f519fb-7c84-4108-b959-4c7a17ffce85")
find_similar("Dark Confidant", limit=10)
search_design_knowledge("how to build a good reanimator archetype")
```

The data behind these tools:
- **33,573 cards** with 768-dim AI embeddings (OpenAI)
- **95,774 card prices** from Mana Pool (refreshed daily)
- **11,907 podcast transcript chunks** from Lucky Paper
- **EDHREC commander data** with synergy scores and bracket filtering
